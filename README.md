# La Compra · versiones

Versiones publicadas de la app La Compra para Android.

- `version.json`: la última versión. La app lo consulta al abrirse y, si hay una más nueva, ofrece actualizar sin perder la lista.
- `apk/`: los APK de cada versión.

Para instalar a mano, descarga el APK más reciente de la carpeta `apk/`.
